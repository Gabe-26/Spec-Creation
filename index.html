Picket library

Add pickets from STEP files

In Fusion 360, export each picket with File > Export and choose STEP. Any orientation works. The app finds the width, thickness and length, and treats the shaped end as the top (use Flip top/bottom if it guessed wrong). A file with several parts lists each one so you can tick the pickets.
